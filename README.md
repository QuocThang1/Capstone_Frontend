# Task Management Platform - Frontend

**Status:** Ongoing
**Backend Repository:** https://github.com/QuocThang1/Task_Management_BackEnd

## Overview
This repository contains the frontend source code for the Agile Task Management Platform. The application provides a collaborative workspace inspired by Agile workflows, featuring interactive Kanban-style boards designed to enhance team productivity and streamline daily development operations.

## Technologies Used
* React.js
* Socket.io-client
* RESTful API Integration

## Key Features
* **Interactive Kanban Boards:** Developed intuitive boards with smooth drag-and-drop functionality for seamless task management and status updates.
* **Real-time Synchronization:** Integrated Socket.io-client to reflect live task updates, state changes, and team interactions instantly across all connected users without page reloads.
* **Workflow Visualization:** UI components built to clearly display task progress and highlight potential workflow blockages identified by the backend.
* **Responsive Design:** Optimized layouts for various screen sizes to ensure a consistent user experience.
